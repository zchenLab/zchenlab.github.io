# PDFs

Save each article's PDF here under the file name given in `download_links.html`
and in the Word file (for example `Razaz2024_JAMANeurol.pdf`).

Open `download_links.html` in Chrome. Links with a DOI go through the UGA Libraries
proxy (proxy-remote.galib.uga.edu) and ask for your UGA MyID. The others open a
Google Scholar search, where you can use the "UGA Full Text" or GALILEO link.

The PDFs were not downloaded automatically: the cloud session that made this list
could not use the Claude in Chrome extension or sign in to UGA/GALILEO.
